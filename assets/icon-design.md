# TouchMouse icon generation record

The application icon combines a mouse pointer with a touch/tap symbol.

Generated with the built-in image_gen tool. Original PNG copied into `touchmouse-icon.png`; `TouchMouse.ico` exports 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 px frames with transparency. No visual editing was applied during format export.

## Final selected prompt

Use case: logo-brand. Create one polished Windows 11 / WinUI 3 style app icon for TouchMouse, a utility that makes touch taps work as mouse clicks in old games. A simple, elegant combination of a mouse pointer and a subtle touch/tap symbol. Flat Fluent design, clear silhouette, tasteful restrained color, no text or letters, no mockup, no elaborate 3D or glass. Transparent background. Make the actual icon large in the square canvas, with only a small safety margin, so it looks the same size as other Windows app icons and remains legible in the notification area.
